# 安装选择

查看可安装内容和本地已安装内容，以及安装、清理和移除 Agent、技能与规则时使用的术语。

## Language

**技能来源 (Skill source)**：
提供可安装技能的仓库。同一个来源可以提供多个技能。

**技能身份 (Skill identity)**：
由技能来源与技能名称共同确定。同名但来自不同来源的技能互不等同，来源无法确认的独立副本也视为不同技能。

**技能安装条目 (Skill installation entry)**：
某个 agent 中代表技能的目录、文件或软链接。同一个技能可以对应多个安装条目，直接指向已有技能的改名链接仍代表原技能。

**技能外部引用 (External skill reference)**：
本次未选入删除范围、但通过软链接使用待删除技能的 agent 安装条目。共享整个技能集合的目录链接不属于某个技能的单独引用。

**技能依赖 (Skill dependency)**：
一个技能运行时明确需要加载或调用的另一个技能。推荐的工作流顺序和项目配置前置条件不属于技能依赖。

**手动选择 (Explicit selection)**：
用户明确要求安装的技能，即使没有其他技能依赖它，也保留选择。

**自动补齐 (Automatic selection)**：
为满足已选技能的直接或间接依赖而加入的选择。没有任何手动选择的技能再需要它时，该选择随之移除。

**连带取消 (Cascading deselection)**：
取消一个技能时，同时取消所有直接或间接依赖它的已选技能。

**规则来源 (Rule source)**：
提供规则内容的仓库。规则来源与规则安装后生效的范围相互独立。

**规则安装条目 (Rule installation entry)**：
指定安装范围中的完整规则文件或软链接，是规则卸载时的选择单位。全局条目归属于某个 agent，项目条目由项目共享；一个文件可以包含规则和用户手写内容。

**安装范围 (Installation scope)**：
技能和规则安装所面向的范围。全局范围面向用户的各个项目，项目范围仅面向选定项目。

**安装计划 (Installation plan)**：
执行前供用户确认的拟安装内容及其目标，包含选定的技能和规则的来源，或选定的 Agent CLI 及其附带组件。

**附带组件 (Bundled component)**：
选择某个安装项时一并安装的组件，不提供独立勾选；取消所属安装项后，不再安装该组件。取消选择不卸载已有组件。

**已安装清单 (Installed inventory)**：
`List → Local` 展示的本机规则与技能条目，按所选安装范围和 Agent 查看，也包含可识别的手动安装项和软链接。

**Agent 命令入口 (Agent command entry)**：
通过 `PATH` 找到的 Agent 命令路径。同一个 Agent 可以有多个命令入口，搜索顺序中的第一项为当前入口。

**Agent 实际可执行文件 (Agent executable)**：
Agent 命令入口沿软链接解析后的最终文件。启动脚本本身也可以是实际可执行文件。

**可安装目录 (Available catalog)**：
由配置的技能来源和规则来源提供的候选条目，可用于选择安装项，也可通过 `List → Remote` 查看远程来源提供的内容。

**Agent 清理 (Agent cleanup)**：
移除可重建的本地文件或用户选中的附带组件，保留 Agent CLI、会话和凭据。

**Agent 卸载 (Agent uninstall)**：
移除选中的 Agent CLI 及该 Agent 的用户级配置、凭据和历史。Agent 独有的技能与规则可随卸载移除，共享技能由技能与规则入口管理。
