# 工具更新

工具管理命令中用于区分更新范围的术语。

## Language

**更新范围 (Update scope)**：
一次更新所涵盖的全局技能、Agent 及其组件和 Homebrew 软件包。某项处于更新范围内，仍需满足该项的更新条件。

**默认更新 (Default update)**：
涵盖已安装的全局技能、Codex 及其插件市场，以及 Homebrew 软件包的更新范围。

**完整更新 (Full update)**：
在默认更新范围上加入 Claude Code、Pi 和 Hermes Agent，另涵盖支持更新的 Claude 插件市场、Claude 插件和 Pi 扩展。
